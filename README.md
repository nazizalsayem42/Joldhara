# Joldhara Properties Limited Website

A modern real estate landing page inspired by [joldharapropertiesltd.com](https://www.joldharapropertiesltd.com/).

## 🌟 Highlights
- **Full Parallax Carousel**: Auto-rotating hero with 5 high-resolution backgrounds.
- **Scroll Reveal Animations**: Smooth transitions for statistics, project cards, and offices.
- **Responsive Mobile Drawer**: Optimized navigation across mobile, tablet, and desktop.
- **Project Showcase**: Card zoom effects, specs overview, and interactive details modal.
- **Direct WhatsApp Chat**: One-tap floating WhatsApp messaging button.
- **Dual Edition**: Includes both a Next.js 14+ app AND a standalone static `index.html` file that runs in any browser without installation.

## 🚀 Quick Start

### 1. View Instantly (No Node.js needed)
Open `index.html` directly in your browser.

### 2. Next.js Development
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000).
